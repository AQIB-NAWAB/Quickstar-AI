QuickStart AI chat widget

This is a customer-site example. Configure a publishable key in the script tag below, add this page's origin to that key's allowed origins, and publish the agent.

Open the launcher in the lower-right corner to chat. The visitor and conversation are saved in this browser, so reloading the page restores the same thread.

For local use, serve this file from http://127.0.0.1:8080, add that exact origin to the publishable key, and run the QuickStart web app on port 3005.
