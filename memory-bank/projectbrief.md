# QuickStart AI — Project Brief

## 1. Overview
QuickStart AI is a production-grade, multi-tenant AI agent platform enabling businesses to create, configure, train, deploy, operate, and monitor AI agents across multiple channels (web chat, voice calls inbound/outbound, internal apps, workflows, APIs/SDKs).

The project is executed following a structured 60-day roadmap (30 2-day slots: Day 1 Learn, Day 2 Build).

## 2. Tech Stack & Architecture
- **Language/Runtime:** Node.js 22+ with TypeScript (ESM)
- **Package Manager:** pnpm 9+ (monorepo with `pnpm-workspace.yaml`)
- **Linting & Formatting:** ESLint 9 (flat config), Prettier
- **Testing:** Node.js native test runner (`node --test`)
- **Data Plane (Local Docker Compose):**
  - PostgreSQL 16 (Relational & tenant data)
  - Valkey 8 (Redis-compatible cache & ephemeral state)
  - Apache Kafka 3.9 (Event streaming / message broker)
  - OpenSearch 2.19 (Search & vector retrieval / RAG)
  - OpenTelemetry Collector Contrib 0.122 (Observability: traces, metrics)
  - ElasticMQ Native 1.6 (Amazon SQS compatible queue)
- **Deployable Topology (Future / Cloud):**
  - AWS EKS / Kubernetes
  - Terraform for IaC
  - Helm charts for deployment configs

## 3. Monorepo Structure
- `services/`: Deployable domain services (starts with `_template`)
- `packages/`: Shared platform libraries
  - `@quickstart/contracts`: Standard envelopes, schemas, interfaces
  - `@quickstart/errors`: AppError, error codes, HTTP error handling
  - `@quickstart/logging`: Structured JSON logging, PII redaction
  - `@quickstart/tracing`: OpenTelemetry distributed tracing helpers
  - `@quickstart/auth`: Multi-tenant auth context & JWT helpers
  - `@quickstart/utilities`: Circuit breakers, retry logic, Redis helpers
- `docs/`: Product specification (`project_details.md`), 60-day plan (`roadmap.md`), ADRs (`adr/`), runbooks
- `infra/`: Terraform configs & local infrastructure configurations
- `deploy/`: Helm charts & deployment manifests
- `sdk/`: Client SDKs
- `tests/`: Cross-service integration & end-to-end tests
